# Работа с консолью

Для запуска программы используйте файл `main.dart`

Принимаются следующие параметры:
 - action - действие, совершаемое над массивом
 - help - помощь

Вызов команды с параметрами `main.dart action --action=1` или `main.dart action -a1`

Для вызова всех имеющихся действий используйте `main.dart action --help` или `main.dart action -h`
